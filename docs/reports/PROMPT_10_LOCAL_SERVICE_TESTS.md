# Prompt 10 Local Service Tests

Deterministic adapters cover Meta webhook verification, replay/deduplication,
provider error mapping, policy windows, retries, idempotency, CRM exports, AI
schema/privacy, credential encryption and Turnstile action/hostname/freshness.

No paid provider credit, live Meta call, customer record or real outbound send
was used. `LIVE_PROVIDER_SEND_ENABLED=false` is the default and required
Preview posture.
