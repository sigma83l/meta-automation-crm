# Prompt 10 UI/UX Report

Signal Mirror is applied to Auth, onboarding, Overview, Inbox, Automations,
Recipe Gallery, Test Center, CRM, Analytics, Integrations and Settings. The
shell uses desktop/tablet rails and the five-item mobile action bar. Dense work
surfaces remain opaque; glass and cinematic treatments are limited to the
approved shell surfaces. All core controls have real routes or server actions.

Owner-critical recovery, empty, disconnected, offline, reauth, policy-blocked
and safe Sandbox states are represented. Real send remains visibly disabled.
