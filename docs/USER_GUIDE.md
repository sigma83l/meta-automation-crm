# Business Owner Guide

## Start safely

Create an account, then use the resumable onboarding checklist. Complete the
business profile, approved prices and FAQs, AI provider choice, Sandbox channel
connections, first automation, safe test and activation in that order.

Sandbox mode never contacts a real recipient. The header and navigation retain
the no-send status so it is not confused with Live mode.

## Daily routes

- **Overview:** see setup, connection health, active automations, open trusted
  service windows, new customers, human review and recent errors.
- **Automations:** choose one of the three supported recipes and complete all
  seven configuration steps. Run a safe test before activation.
- **CRM:** search, filter, edit, upload private media and request workspace
  Excel/ZIP exports.
- **Inbox:** inspect the policy window and collected context. A human reply
  pauses automation; only explicit Resume returns ownership.
- **Integrations:** connect deterministic Sandbox assets, check health,
  reauthorize or disconnect. Token values never appear.
- **Settings:** maintain the business profile, prices, FAQs, response style,
  encrypted AI credential status, retention and account controls.

## Emergency actions

`Pause now` prevents new automation work. `Stop queued messages` cancels only
queued/retrying steps for the selected automation. `Take over conversation`
changes the owner to human and records the actor/reason. Reconnection is
required for a connection in `NEEDS_REAUTH`.

These controls do not bypass consent, opt-out, service-window, quiet-hour,
frequency-cap, confidence or recipient-allowlist policy.

## Mobile and accessibility

Mobile navigation is Home, Automations, Create, CRM and More. Inbox shows one
panel at a time with a back link. Controls use semantic labels, a visible focus
ring and logical layout properties. The 390 px RTL path is regression-tested;
content language translation is future product scope.
