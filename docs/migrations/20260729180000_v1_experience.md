# 20260729180000 V1 experience

Adds bounded UI preferences and resumable setup draft state:

- `profiles.locale` and `profiles.theme`;
- workspace defaults for locale/theme, category and country;
- onboarding skipped stages, bounded draft JSON and last-saved time.

The migration is additive and defaults existing rows safely. Rollback requires
first removing application reads/writes, then dropping only the added columns
and `private.valid_onboarding_stage`. Do not roll back after relying on saved
setup data without an export and owner approval.
