# Public V1 Launch Gates — G0 to G14

**Source page:** 37

No public launch until every hard gate passes.

| Gate | PASS requires |
|---|---|
| G0 Repository Truth | repo/SHA/routes/migrations/tests/provider projects documented |
| G1 Schema & RLS | migrations on staging + cross-tenant denial tests |
| G2 Auth/Account | verification/recovery/provisioning/RBAC/trial state |
| G3 Meta | real allowlisted pilot + webhook/send/reconnect evidence |
| G4 RCOS/AI | golden tests + validator + tool verification + no duplicate send |
| G5 CRM/Automation | memory/state/follow-up/handoff/booking outcome verified |
| G6 Paddle | sandbox→production webhook verification/reconcile/entitlement |
| G7 Usage/Trial | meters/caps/expiry/grace/read-only/delete pass |
| G8 Site/App Contract | final UI surfaces bound to real backend/read models + truth registry |
| G9 Analytics | event taxonomy + attribution + privacy boundaries |
| G10 Email/Support | auth email, transactional delivery, ticket flow, webhook status |
| G11 Reliability | observability, load, queue, backup/restore, incident runbook |
| G12 Human UAT | owner/operator workflows + blocked/recovery states |
| G13 Allowlisted Pilot | real outcomes, no P0/P1, controlled live send |
| G14 Public Launch | all hard gates + exact SHA + rollback + monitoring |
