# Public Web → Backend Route Contracts

**Source page:** 26

| Route family | Backend dependency | Production rule |
|---|---|---|
| Core locale routes `/`, `/tr`, `/fa`, future `/ar` | claim registry + locale content | indexable |
| Industry: beauty/clinic/real-estate | proof/workflow registry | index only if substantial + unique |
| Use cases: IG DM/WhatsApp/follow-up/booking/handoff | product truth + scenario data | no unsupported live claim |
| Demo | synthetic/Test Center scenario API or static trace | label sandbox/synthetic until real |
| Compare | versioned competitor fact registry | source checked/current; no attack copy |
| Templates | approved workflow templates | only useful + tested |
| Resources | CMS/content registry | people-first; source/update date |
| Partners | partner application + attribution | server validation + consent |
| Customers | case-study evidence registry | gated until permissioned real proof |
| Access/Trial | release gate + auth/app handoff | CTA follows real trial readiness |
| Pricing | canonical pricing_config + plan_entitlements | never stale hard-coded values |
| Contact/Support | server-side form + ticket/event | Turnstile/rate limit + async email |

## SEO/backend rules

- Canonical locale paths.
- No indexable UTM duplicates.
- No fake customer proof.
- Dynamic content must remain consistent with truth registry.
